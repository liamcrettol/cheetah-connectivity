## Open at home

1. Pull or download this repository.
2. Double-click the `.ppkx` file, or open it from ArcGIS Pro with **Open project package**.
3. Extract it to a local working folder (for example, `C:\cheetah_home\resistances`).
4. Open the extracted `.aprx` and use **Save As** to create your own working copy before editing.

The package was created with external data consolidated, project toolboxes included, writable output, and no geoprocessing history items. The original project at `C:\cheetah\resistances` was not modified. Online basemap/service layers may still require an internet connection and an ArcGIS sign-in.
