# Asiatic-style manuscript map project

The file `asiatic_style_maps_20260913.ppkx` is the current portable ArcGIS Pro
project for continuing the manuscript maps on another computer.

## Opening it at work

1. Pull or download the latest `main` branch.
2. Open `arcgis_project/asiatic_style_maps_20260913.ppkx` in ArcGIS Pro.
3. Choose a local extraction folder when ArcGIS Pro asks.
4. Save the extracted project under a new local name before making changes.

The package is writable and compatible with ArcGIS Pro 3.6 and later, including
3.7. It contains the data used by the maps, eight map views, eight page layouts,
legends, scale bars, north arrows and reusable symbology.

## Maps and layouts

- Figure 1: study area, 23 cores and four descriptive core groups.
- Figure 2A: outside-core current percentile in 2024.
- Figure 2B: change in outside-core current from 2012 to 2024.
- Figure 3: 32 primary and 13 uncertain modelled links with roads and available
  fence records.
- Figure 4A-D: Northwest, Central, Southern and Eastern detail views.

The 25-km group polygons are only visual guides and zoom extents. They have no
biological meaning and can be hidden in the final maps.

The package does not contain separate outside-core current rasters for 2012,
2016 and 2020. It therefore does not contain a four-year current panel.
