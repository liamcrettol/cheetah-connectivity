## Opening at home

Open the `.ppkx` in ArcGIS Pro and extract it to a local working folder. The package contains the project and referenced data needed for the map layouts. Online basemap layers may require an internet connection and ArcGIS sign-in. The exported PDFs are suitable for manuscript review; use the PNGs for quick previews or figure assembly.

This is a snapshot of the completed map styling/layout work. Keep the original project and the analysis repository scripts as the authoritative provenance for data processing.
